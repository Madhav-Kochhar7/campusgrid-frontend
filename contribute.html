CampusGrid / Contribute Compute

Join the CampusGrid Network

Donate your idle computing power to help fellow students train models and run simulations faster. Setup takes less than 2 minutes.

Module 01

Agent Deployment

Run the install script in your terminal to download the agent daemon. Choose the correct script for your OS.

curl -sL https://campusgrid.local/install.sh | bash
iwr -useb https://campusgrid.local/install.ps1 | iex
Module 02

Grid Authentication

Link your local agent to your account by generating a secure auth token. Run the command below to inject the token.

campusgrid auth set cg_tok_8f92j3nfa0923fna82309f
Module 03

Status Verification

Check the status of your local agent to ensure it is communicating with the main cluster.

campusgrid status

Agent Active

If the output shows "Status: Connected", you are successfully contributing to the grid! Your node will appear on the Dashboard shortly.
